# 📊 Vrinda Store Annual Report 2022 — Excel Dashboard

An interactive **Excel Sales & Order Analysis Dashboard** created to analyze Vrinda Store's 2022 sales performance and customer/order patterns.

## 📌 Project Overview

This project focuses on transforming sales data into an interactive dashboard that provides a clear view of business performance across different dimensions such as **monthly sales, customer demographics, order status, product categories, states, and sales channels**.

The dashboard uses Excel's interactive features to make the analysis easy to explore and understand.

## 🎯 Objectives

* Analyze monthly **sales and order trends**
* Compare sales between **men and women**
* Understand **order status distribution**
* Identify the **top-performing states**
* Analyze orders by **age group and gender**
* Understand sales/orders across different **sales channels**
* Provide an interactive dashboard for business performance monitoring

## 📊 Dashboard Analysis

### 1. Orders vs Sales

Analyzes the monthly relationship between:

* Total sales amount
* Number of orders

### 2. Sales: Men vs Women

Visualizes the distribution of sales between male and female customers.

### 3. Order Status

Provides an overview of orders based on statuses such as:

* Delivered
* Cancelled
* Returned
* Refunded

### 4. Sales: Top 5 States

Highlights the top-performing states based on sales amount.

### 5. Orders: Age vs Gender

Analyzes order distribution across:

* Adult
* Senior
* Teenager

and compares the results between men and women.

### 6. Orders: Channels

Analyzes order distribution across different sales channels, including:

* Amazon
* Myntra
* Flipkart
* Ajio
* Meesho
* Nalli
* Others

### 7. Category Analysis

The dashboard provides interactive filtering across product categories such as:

* Blouse
* Bottom
* Ethnic Dress
* Kurta
* Saree
* Set
* Top
